My day job is the closest thing to forward deployed engineering I know of. I'm the person on site who makes the technology work for a real operation, working with engineering and IT at headquarters in Germany. Here's a slice of what I've built there.

The warehouse planner's 3D view: CAD layout merged with phone scans of the empty building.

Warehouse planner, 2D + 3D

new facility buildout · used by the KRUU US team
in use

When we took a new building, I built the tool we planned it in. It's one page with a 2D floor plan and a 3D view, built from the architect's PDF and LiDAR scans of the empty building. It lays out shipping shelves, check and clean rows, conveyors, racks, and building steel, and it runs the power plan with panel schedules and load checks plus a data port plan, with PDF, PNG, and Excel exports. It also loads the conveyor vendor's own CAD model (8,990 parts from their STEP file) so we could check their layout against ours before anything was installed. I packaged it so our German site can rebuild it for their warehouse.

three.js LiDAR scans · glTF STEP to mesh PDF floor plan parsing Power & load calcs Python tooling

Facility IT buildout

I own IT and workshop for the move: internet cutover, network and switching to every fulfillment shelf, bringing the building's inherited access control and camera systems onto our network, and the shelving layout, power distribution, and cabling.

MiLa test station

Raspberry Pi pass/fail rig for USB microphone units. Plays a frequency sweep, records it back, and validates the capture in about five seconds, with auto plug-in triggering, LED and beep output, and self-calibration.

Printer test rigs code ↗

Plug in a DNP or Canon SELPHY printer and the rig detects it over USB and runs a 10 image QC suite (color, resolution, text, edge bleed) with a live web dashboard. Headless, with a one command reset for the floor.

DNP print server code ↗

Pi based photo print station: drag photos into a web page or a shared folder and they print at 4x6, 4x4, or cut strips. One command installer that detects the printer and user on its own.

Photobooth Test Box

A diagnostic box for the fleet that checks the 24V supply, USB voltages, the pedal switch, and cable continuity, so a tech can find a fault in minutes instead of swapping parts.

Floor dashboards & parts

Metabase dashboards on Pi kiosk screens and a mobile fulfillment widget for live throughput and first pass yield. CAD and 3D printed parts for the fleet, like a retention clip for the DNP printers.

the centerpiece · a living experiment

Operant

A persistent reinforcement-learning organism, shaped forever by everyone who visits.

A small learning mind lives on a server and never stops. It moves, it learns, and every visitor who has ever been here has changed it a little, permanently, through reward and punishment. Nothing is ever undone. It's part art installation and part engineering piece, inspired by Sun Yuan & Peng Yu's Can't Help Myself and by simulation theory. Built as a TypeScript monorepo: a framework-agnostic Q-learning core, an always-on simulation host that owns and persists the single agent, and a react-three-fiber 3D view for observers, with the learning core kept strictly decoupled from rendering.

Argus

fully-local AI home monitor · self-hosted
AI / inference

A fully-local, AI-powered home-monitoring and face-recognition system for Home Assistant. No cloud, and everything runs on your own hardware. It's three cooperating services: a Watcher that snapshots the home's state every few minutes and asks an LLM "is anything actually wrong?" (a hardened, high-signal prompt with an urgent-push vs. daily-digest policy); a Recognizer running InsightFace on CPU, exposing a CodeProject.AI-compatible API to detect and identify faces on-device; and a Console that clusters unknown faces by similarity so you name a group once and it learns that person from then on. Pure logic is unit-tested; the container and glue layers are dry-run-verified.

Python LLM reasoning loop InsightFace On-device / CPU inference Face recognition Home Assistant · AppDaemon Docker / Compose Flask API Pytest
